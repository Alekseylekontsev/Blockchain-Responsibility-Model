## Standards and copyright

ISO/IEC standards are copyright-controlled and are not redistributed in this public repository. BRM stores the standard identifier, edition, status, official landing page, and a derived crosswalk that does not reproduce protected text. Licensed full-text locations belong in a private implementation register.

The ISO/TC 307 portfolio is maintained in [`../iso-tc-307-landscape.md`](../iso-tc-307-landscape.md). Supporting implementation standards commonly include ISO/IEC 27001, 27002, 27005, 27035, 27036, 27701, 29100, 29134, ISO 22301, ISO/IEC 20000-1, 29147, and 30111. Pin exact editions and licensed access sources.

## Integrity procedure

If redistribution-permitted files are vendored into an archival branch, record official URL, retrieval timestamp, SHA-256, byte size, media type, language, edition/version, issuer, licence, and superseded/current status. Never silently replace a source; add a new version so earlier BRM decisions remain reproducible.
