# N7 dApp — worked example

Prepared by [DPO Aleksey Lekontsev](https://lekontsev.uk/).

This illustrative example applies the BRM formula to one concrete responsibility record. It deliberately includes a privileged upgrade right and evidence references so a reviewer can reproduce the allocation.

The record is validated against [`../../schemas/responsibility-record.schema.json`](../../schemas/responsibility-record.schema.json). The `evidence/` paths are placeholders for the controlled evidence pack; they are not claims that the evidence exists.
