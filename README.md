# Blockchain Responsibility Model

A responsibility and accountability model for secure blockchain, Web3, DeFi, and dApp delivery.

## Repository status

This repository is under active development. Documents marked **Draft** capture working ideas and are not approved policy or normative requirements.

## Documents

- [DeFi dApp Development Project Lifecycle](standards/defi-dapp-development-lifecycle.md) — 11-stage secure delivery lifecycle with security gates and per-stage RACI assignments. **Status: Draft.**

## Model direction

The repository is intended to connect:

- lifecycle stages and decision gates;
- governance, security, engineering, product, risk, compliance, audit, and incident-response roles;
- responsibility assignments using RACI;
- evidence required to approve releases and operational changes;
- lessons from major blockchain and DeFi incidents.
